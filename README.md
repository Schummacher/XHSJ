# 小鹤四角（XHSJ）

小鹤四角是一套基于 Rime 的混合输入方案，使用“小鹤双拼”提供音码，以四角号码或相关形码数据提供形码辅助手段，并保留了顶功式编码的实验素材。

## 当前状态

当前版本是可部署的中文输入方案原型，暂未冻结最终形码规则。仓库中的 `jmma`、`qrma` 等词库是候选编码资源，默认不直接导入；正式主词典只启用下方列出的词库。

## 默认词库

主词典 `xhsj.dict.yaml` 默认导入：

- `xhsj.erma`：小鹤双拼单字音码
- `xhsj.sima`：中文音形词库
- `xhsj.sjma`：中文形码及短序列词库
- `xhsj.nhg`：日文及其他音节资源
- `xhsj.han`：汉语及常用字资源
- `xhsj.eng`：英文词库
- `xhsj.jap`：日文词库
- `xhsj.japq`：日文带权重词库
- `xhsj.fan`：繁体词库
- `xhsj.tib`：藏文词库
- `xhsj.nom`：越南语词库

以下词库仍保留在仓库中作为编码候选，但默认不导入：

- `xhsj.jmma2`、`xhsj.jmma3`、`xhsj.jmma4`
- `xhsj.qrma1`、`xhsj.qrma2`、`xhsj.qrma3`、`xhsj.qrma4`、`xhsj.qrma5`
- `xhsj.dj`

只有在明确选择一套形码规则并完成兼容性测试后，才应启用上述候选词库。

## 编码说明

方案同时保留不同长度的候选编码，实际体验取决于词典条目及 Rime 排序：

- 双拼音码以小鹤双拼规则组织声母和韵母。
- 中文形码词条使用数字或字母等附加编码区分候选项。
- 词组可以继续保留到四码、六码或更长编码；仓库中尚未提供统一的最大码长约束。
- 顶功边界、禁顶规则和按键绑定尚未在配置中完整定义。

仓库中的词典是资源原始数据，不代表已经验证过的正式编码规范。任何形码规则变更都应先更新词库，再更新本说明。

## 安装

1. 准备 Rime 用户资料目录：
   - macOS：`~/Library/Rime`
   - Linux：`~/.config/ibus/rime` 或对应发行版目录
   - Windows：用户的 Rime 配置目录
2. 将本仓库中的 `xhsj.schema.yaml` 和需要的 `xhsj*.dict.yaml` 复制到用户资料目录。
3. 在 Rime 方案列表中启用 `xhsj`，重新部署。
4. 默认候选键为 `甲乙丙丁戊`，候选选择键为 `ABCDE`。

不要只复制 `xhsj.schema.yaml`；主词典的 `import_tables` 会同时加载上述默认词库。

## 反查与切换

按反引号 `` ` ``进入反查模式。具体反查词典取决于 Rime 默认预设及后续补充配置。

方案保留中西文、全半角和中英文标点切换：

- 中文／西文切换由 Rime 默认按键控制
- 半角／全角切换由方案开关控制
- 中英标点切换由方案开关控制

## 已知限制

- `xhsj` 尚未冻结完整形码拆分规则。
- 顶功规则未全部落入 `key_binder`。
- 部分候选词库包含特殊字符或实验编码，不应直接启用。
- 多音字、常用字首选率和误上屏率尚未经过固定测试集验证。
- `auto_select: true` 表示自动上屏行为已启用，误顶边界需要逐步测试。

## 基础测试

仓库提供不依赖第三方 Python 包的静态测试：

```sh
python3 tests/test_schema.py
```

测试会检查：

- 主词典引用的所有表都存在；
- 主词典不引用不存在的表；
- 候选词库不意外进入正式导入；
- 字典条目没有空代码；
- 固定的中文测试词条仍然存在。

## 当前建议

优先用途是个人试用、编码对比和词库验证，不建议在未执行固定测试集前宣称已稳定发布。
